# 牺牲 0.20.72 · 可游玩的测试版

这是一份供试玩和收集反馈的预发布版本，不是稳定正式版。游戏提供完整的回合对战流程，适合先完成新手教程，再与 AI 或朋友对战。

## 开始游玩

- [浏览器直接游玩](https://sacrifice.shytomato.top/)：建议优先使用电脑浏览器。
- [Windows 下载与版本附件](https://github.com/HongyiSi/sacrifice/releases/tag/v0.20.72-test.1)：下载 `Sacrifice-0.20.72-Windows-x64.zip`，完整解压后运行 `Sacrifice.exe`。需要 Windows 64 位系统；无需安装 Godot。
- 大厅中的「新手教程」通过两回合练习介绍基本规则和操作。「本地 AI 对战」可以单人游玩，「创建房间／加入房间」用于好友联机。
- 程序和 `Sacrifice.pck` 必须保留在同一目录。本地 AI 与教程可离线运行，线上房间需要联网。

## 本版内容

- 60 种普通牌、128 张初始牌库卡牌、20 种亡语牌，以及效果生成的诅咒牌。
- 三棋子独立手牌、优先级结算、亡语和两种获胜方式。
- 两回合新手教程：红框引导、上一步、出牌与撤回、换牌、选取目标和结算说明。
- 教程中的防御与疗伤牌避开教学框；格挡、连击、回复等动画完整播放后，再等待玩家确认继续。
- 好友联机、自动重连、本地 AI，以及实验性的自学习 AI。

## 已知问题与限制

- **iPhone Safari 偶发崩溃尚未确认彻底解决。** 已有内存优化和恢复机制，但本次没有进行实体 iPhone 的长时间稳定性验证。建议优先使用电脑试玩；不要将本次发布理解为手机崩溃已经修复。
- 首次打开网页版需要下载资源，耗时受网络速度影响；后续可复用未变化的资源缓存。
- 自学习 AI 仍为实验功能，卡牌强度和胜率仍在调试。AI 的测试结果不能代表真人对战已达到平衡。
- Windows 包未经过代码签名，系统可能显示发布者未验证提示。请从本仓库的发布页取得文件，并按需使用附件中的 SHA-256 校验值核对。
- 网页版会持续更新；本次 Windows 包与源码标签固定为 `v0.20.72-test.1`。未来联机协议升级后，旧客户端可能需要更新。

## 检查范围

发布前通过 16 组、7,808 项规则与恢复检查，涵盖教程、无收益自动效果、化牌为刃、取义、宝石、一次性亡语记录、手牌上限、阵亡后的被动效果、目标选择、跳过效果、提前结束回合、自动重连、AI 对局保存恢复及两种 AI 的合法操作。检查次数包含对局逐步恢复断言，不代表覆盖全部可能的局面。

原生界面与网页版均走通完整两回合教程，包含动画完成后的等待及上一页回退检查；公网双客户端完成建房、加入及同步进入下一回合。Windows 程序完成启动检查，资源包通过 106 项发行检查、55 项教程检查及完整教程播放检查；Windows 联机未单独做端到端验证。以上检查不能保证不存在其他缺陷。

旧回归用例中涉及取义无收益触发、7 点生命上限、化牌为刃新优先级和单目标、终舞先选齐目标的预期已同步到现行规则；没有为让测试通过而修改游戏规则。
