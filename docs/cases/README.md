# 系统策划案例导读

[返回作品首页](../../README.md)

建议先看一分钟演示，再按下面的顺序阅读。每个案例都从玩家面临的问题出发，列出规则取舍、实现落点、验证证据和局限。

1. [击杀的机会成本：亡语与双胜利条件](death-and-victory.md)——核心玩法如何产生反直觉但可理解的决策。
2. [把 AI 用作平衡测试工具](ai-balance.md)——如何提出假设、设置对照，并避免把 AI 的偏好误当成卡牌强度。
3. [反馈、节奏与恢复](feedback-and-recovery.md)——如何从无效动画与移动端崩溃问题出发，改善体验并验证边界。

这些案例围绕一个仍在迭代的项目展开。历史实验的版本和日期单独标出；不把历史结果当作当前规则版本的重新测量结果。
