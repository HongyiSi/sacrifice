# 《牺牲》游戏规则

[返回首页](../README.md)

以下为游戏内「规则」窗口使用的规则介绍。基础数值和操作方式另见[首页](../README.md#基础玩法与规则)，特殊效果以卡牌说明为准。

## 游戏人数

1.游戏共两名玩家。游戏开始时，每名玩家有三个棋子，每个棋子有各自的卡牌。

## 获胜方式

2.游戏的胜利方式有两种：一是击败所有的敌方棋子，二是集齐4个胜利徽章。

## 卡牌类型

3.卡牌分为普通牌和亡语牌，普通牌又分为攻击牌和技能牌。

**普通牌**：普通牌是棋子的手牌，每张牌的左上角是它的主优先级，右上角是次优先级，优先级用于确定卡牌的结算顺序。

**亡语牌**：亡语牌是棋子阵亡后被动触发的卡牌。亡语牌的左上角也有优先级，用于确定亡语牌的结算顺序。

## 回合与阶段

4.游戏分为若干个回合。每个回合分为3个阶段，分别是出牌阶段，结算阶段和亡语阶段。

**出牌阶段**：每个棋子摸一张牌，之后打出一张牌。打出的牌是暗置的，对方看不到我方出了什么牌。

**结算阶段**：开始时所有打出的牌都是暗置的。之后，先按照主优先级的顺序翻开打出的牌，再按照次优先级的顺序依次结算这个主优先级的卡牌。如果一个棋子已经死亡，则它打出的未结算的卡牌就不能结算。

**亡语阶段**：如果有棋子在这回合死亡了，则进入亡语阶段。在亡语阶段，所有本回合死亡的棋子按照优先级顺序依次触发它们的亡语卡。如果有棋子在亡语阶段被杀死，则它的亡语卡也参与本回合亡语阶段的结算；如果有棋子在亡语阶段复活，则它未触发的亡语卡不再触发。

## 补充说明

注：
1.游戏开始时，每个棋子有4张手牌和1张亡语牌。

2.出牌阶段可以不出牌。

3.亡语阶段中棋子的亡语卡进入结算的条件是①棋子是本回合死亡的②轮到它的亡语卡结算时，它处于死亡状态。
