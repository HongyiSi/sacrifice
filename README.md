## 开始游玩

1. 打开线上入口，输入昵称后点击「创建房间」。
2. 把房间号或邀请链接发给好友；好友点击「加入房间」，两人到齐自动开局。桌面本机测试：Launch.cmd →「本机 / 局域网测试」→「本机双开测试」。
3. 悬停手牌查看说明，点击手牌放到棋子前方，点击已打出的牌撤回，最后点击「确认出牌」。未选牌的棋子默认不出牌。通常每个棋子可出一张，额外额度按卡牌效果增加；受到沉默时不能出普通牌。
4. 按提示选择棋子、尚未翻开的牌或数字；也可以点击「跳过效果」，放弃本牌效果但仍消耗卡牌。防御使用者可为被保护棋子取消单体攻击。护符先指定保护对象，再暗置等待响应；出现护符提示时，可以翻开取消整张卡，或保留护符。
5. 棋子死亡后，在亡语阶段按提示处理亡语。即使己方三个棋子全部死亡，仍可操作他们的亡语。终舞每次伤害都重新选择目标；复活时可以选择自己、友方或敌方死亡棋子，以 5 点生命复活。
6. 窥探会显示目标当前手牌与亡语牌，看完后点击「查看完毕」，仅操作者可以查看。神化或手牌超限需要选牌时，在卡牌列表点选，再点击「确认选牌」；也可以使用「自动选择」。苦肉先选择是否发动，再选择至多两张牌。
7. 激活天眼且持有棋子死亡时，点击「天眼 · 查看卡牌」查看手牌、出牌和牌库；复活或失去天眼后，查看权限停止。
8. 每回合结算完毕停留约 1 秒，房主自动开始下一回合，无需点击确认。对局结束后仍由双方同意重赛。

棋子右侧显示己方亡语，点击卡牌可查看效果。对方亡语在进入结算队列之前保持隐藏。当前亡语、剩余伤害次数和待结算卡牌都会显示在界面上。

也可以用 Godot 打开 project.godot，按 F5 运行。启动器使用本机 Godot 4.7.1；换电脑时可通过 GODOT_BIN 指定引擎路径。

局域网：房主创建房间，另一方输入房主显示的 IPv4 地址和相同端口。默认 UDP 端口 24771；本机双开用 127.0.0.1。跨电脑连接需要系统允许局域网通信，本次已验证的是本机双进程。

进入亡语阶段时，只将本回合死亡且此时仍处于死亡状态的棋子所持亡语入队。每结算完一整张亡语，重新从所有待结算牌中选取优先级最高的牌。

亡语造成的新死亡会继续加入队列。终舞造成死亡后仍需完成剩余次数，再结算新产生的普通亡语；不死在每次死亡事件发生时立刻处理。没有合法伤害目标时自动结束剩余次数。亡语伤害不属于普通攻击牌，不触发防御。

终舞每次选择目标时都可放弃：第一次点击「跳过效果」会跳过整张牌；已经造成伤害后点击「跳过剩余效果」，会结束剩余次数。已经造成的伤害和死亡保留，之后继续处理队列中的亡语。跳过复活不会让目标复活，也不会收回目标的待结算亡语。

复活会收回该棋子已经入队、尚未结算的亡语；已消耗的牌不会返还，再次死亡才会让收回的未结算亡语重新入队。已经激活的持续牌不重新入队。已公开的亡语收回后仍对双方可见。翻牌前复活可保留原本尚未翻开的普通牌；已取消或错过翻牌的牌不会恢复。

所有亡语处理完毕后才判定全灭胜负。双方暂时全灭时仍继续处理队列，如果最终都没有存活棋子才判平局。预言达到四枚徽章的立即胜利规则保持不变。

## 新亡语的操作与结算约定

- 持续性亡语只激活一次，之后保留。持有者复活后再次死亡，保留原效果，不重新入队或重新选择目标。禁锢、保佑绑定所选棋子；特权和贪婪影响全体友方棋子，直到来源牌失去。保佑让攻击牌对其指定棋子无效，同时禁止其回复生命，不会保护同一群体攻击的其他目标。复活不属于回复生命，仍按卡面设置生命。
- 不死是卡面明确写出的例外：死亡事件发生时立刻结算。有其他存活队友则立即以 1 点生命复活，可以反复触发，凡庸和诅咒都不能弃置不死。复活不会撤销已经发生的死亡事件；未翻牌时即复活可保留出牌，已取消的牌不会恢复。
- 凡庸的合法目标必须存活；凡庸或诅咒弃置亡语时，相关持续能力立即停止。
- 神化和天眼只有在已经激活且持有者死亡时发挥能力。复活暂时停止这两种能力，再次死亡后恢复；失去来源牌则彻底停止。其他玩家看不到神化操作者的牌库选项或手牌超限的弃牌选项，除非自己拥有生效中的天眼。
- 神化由持有者为摸牌者挑选；手牌超限由获得牌的棋子所属玩家选择弃牌。已经进入的强制选牌步骤不能取消，可以点击「自动选择」。牌库不足时先选完现有牌，再洗回普通弃牌继续选牌。
- 禁锢按整次摸牌检查：有手牌就取消整次摸牌，空手则允许摸到本次数量。禁锢先于神化检查，不能利用神化绕过禁锢。
- 所有死亡棋子均可被伤害牌选择，但苦肉仅在已激活该能力的死亡棋子受到其他队友伤害时触发。敌人攻击该棋子不触发苦肉；第一次致死也不触发苦肉。
- 苦肉会暂停当前效果，让造成伤害的队友选择是否摸牌，再选择至多两张普通手牌立即打出并翻开。额外牌等当前整张牌完成后才按优先级结算；亡语阶段仍先处理待结算亡语。这一顺序已由你确认。
- 死亡棋子仍不能使用普通实体手牌，因此若苦肉的伤害来源棋子已经死亡，只执行其可选摸牌，不追加普通实体牌。幽灵和魔镜按各自卡面保留死后使用虚拟牌的例外。
- 心脏结算后实体牌交给目标，额外出牌只对下回合有效。持有心脏的棋子之后死亡时，可以再次结算并转交心脏。
- 诅咒进入普通手牌栏并占用手牌数量。它不能打出，且永远不能以任何形式弃置，包括手牌超限、消逝、赌徒和悲歌代价。掠夺属于转移而非弃置，转移后仍受此限制。出牌阶段开始时先结算诅咒伤害，再摸牌；若造成死亡事件，即使不死立即复活，仍会弃置该棋子除不死外的亡语。
- 幽灵仅在棋子处于死亡状态时，在后续出牌阶段自动产生随机一种名称含“打击”的虚拟普通牌，次优先级为100，不消耗普通牌库。特权使所有友方棋子的普通牌主、次优先级及亡语优先级都加100；来源牌失去时恢复。
- 取义获得徽章后立即检查胜利。贪生只奖励击杀敌方棋子产生的死亡事件；敌人随后因不死复活仍满足条件，击杀队友不满足。

## 新增普通牌的操作与结算

- 护符在暗选时正常打出，系统保留暗置状态，等待卡面条件出现。神圣护符在预先保护的棋子成为普通牌目标时响应；攻击护符在保护目标成为攻击牌目标时响应；魔法护符在保护目标成为技能牌目标时响应。护符必须严格高于被取消牌的主、次优先级，反转不会改变这个比较条件。
- 翻开护符会消耗这张实体牌，并取消目标卡的全部效果，包括其他目标和斩杀奖励。可以保留护符等待后续机会，没用掉的已出护符仍在本回合结束时弃置。护符不会仅因为其他护符翻开而响应，因为此时持有者并未成为该护符的棋子目标。
- 魔法护符也可取消涉及自己在内的群体技能，例如治疗；护符只响应普通牌，亡语不属于普通技能牌。神圣打击现在是攻击牌，受已生效的防御、保佑约束；攻击护符仍必须优先级更高才能取消它，魔法护符不适用。
- 魔镜或苦肉要求直接打出并翻开的护符，已经失去暗置响应条件，不会另行储存一次护符能力。魔镜仍会在被复制原牌翻开时触发，即使原牌随后被神圣护符取消。
- 扭转乾坤在当前主优先级结束后反转剩余普通牌的主优先级顺序，同主优先级仍按次优先级从高到低。苦肉插入的扭转乾坤等被打断的主优先级处理完毕再反转；亡语阶段则立刻反转普通牌顺序。多次使用会多次反转，已完成的牌不重结算，下回合恢复默认顺序。
- 特权棋子的普通牌始终先于没有特权的棋子，反转不取消这一点；卡牌效果失去特权来源时按实际优先级继续。
- 假死立即按优先级结算使用者持有的未激活亡语，使用者无需死亡；整批亡语完成后使用者失去 2 点生命。已激活的持续牌保留原效果，不重新选目标；由此造成其他棋子死亡，其亡语等到正常亡语阶段再结算。这一处理已由你确认。不死按卡面即时复活条件处理，不会把存活棋子的生命改为 1。
- 戏命跳过本回合正常亡语阶段，不取消不死或假死。跳过的亡语留在棋子身上，不因旧死亡在下回合自动触发；之后复活再死亡仍可触发。
- 悲歌先选择弃置两张手牌，再从剩余亡语牌库摸一张；手牌不足两张时整张牌无效果。亡语身份仅己方可见，牌库空时无法摸牌，已经支付的弃牌代价不退还。已消耗的亡语不重新洗入该牌库。悲歌和假死在同一棋子同回合打出时，默认先支付代价并摸亡语，再由假死打出。
- 窥探是一次性查看目标当前手牌及亡语牌，不授予持续追踪权限；查看后点击「查看完毕」。掠夺指定其他棋子并随机转移其一张手牌，包含手牌中的诅咒，不会把转移的牌算成弃置；目标空手时无效果。
- 过载使下回合基础出牌数量变为三张，可叠加心脏和贪婪增加的数量；重复过载不会再增加基础数量。沉默使下回合不能打出普通牌，也阻止该回合的幽灵自动出牌或苦肉追加牌，但仍可摸牌和结算亡语。
- 死者苏生可以选择任意死亡棋子，以 1 点生命复活；疗伤只可选择自己之外的存活棋子，回复 3 点生命且不超过上限。主动选择目标时仍可跳过效果。
- 荣耀打击造成敌方死亡事件后获得一枚徽章，即使敌人随后由不死复活。胜利徽章、荣耀打击和取义的徽章奖励都会立即检查四枚徽章胜利。

## 结算与交互

- 每个棋子初始生命 8、起手三张普通牌和一张亡语牌，每回合存活棋子各抽一张普通牌，使用各自手牌。
- 双方同时暗选。只有询问到对应主优先级时，该批牌才同时翻开；之后按次优先级从高到低结算。对方未翻开的牌及其优先级保持隐藏。
- 棋子死亡会取消其已翻开但尚未结算的普通牌；尚未翻开的牌若在轮到翻开前复活，仍能正常结算。当前正在结算的效果继续完成。
- 防御结算后生效，受到单体攻击指定时可选择使用。选择承受伤害不会消耗防御。使用后取消整张攻击牌的效果，包括悬赏打击的奖励。
- 群体打击按群体攻击处理，即使只剩一个存活敌人，也不触发只针对单体的防御。审判属于技能，同样不触发防御。
- 弑神打击只允许选择本回合已经翻过牌的棋子，包括死亡棋子；同一批同时翻开的棋子也满足条件。
- 魔镜、压制只能选择尚未翻开且优先级更低的牌；同一主优先级已同时翻开的牌不能再被选择。压制或忽视阻止翻牌时，不会触发附着的魔镜。
- 魔镜生成不占用实体牌库的复制牌，主优先级与原牌相同，次优先级为 0。按卡面「即使已经死亡」的特殊说明，复制牌保留死后执行能力。复制群体打击、治疗等效果时，以复制者的队伍为准。
- 预言在普通牌结算结束时检查生命值。队伍达到四枚徽章立即获胜；没有达成徽章胜利时，在亡语阶段后判定整队全灭，双方全灭则平局。
- 技能类回复不能复活棋子，也不能为受保佑的棋子回复生命，生命不超过该棋子当前上限（初始 8，血祭可增加）。治疗包含自己与其他存活队友。
- 悬赏打击只有造成敌方棋子从存活到死亡，才会奖励摸 2 张牌；击杀友方或被防御取消均不奖励。
- 一张实体牌完成结算后进入弃牌堆；未能结算的出牌在回合结束时弃置。魔镜复制牌不会变成额外实体牌。抽牌时牌库不足则洗回弃牌；双方皆空则跳过不足部分的抽牌。
- 本版在牌实际结算时选择目标；可以攻击自己或友方，界面会要求确认。没有合法目标时自动记录无效果并继续。
- 主动选择效果目标或声明数字时提供「跳过效果」，仅使用者可以操作。放弃后本张牌继续按正常规则消耗：普通实体牌进入普通弃牌堆，一次性亡语进入亡语弃牌堆，魔镜复制牌不产生额外实体弃牌。已经完成的效果不回退，也不影响其他正在等待结算的卡牌。
- 跳过与出牌阶段的「本回合跳过」不同：选牌阶段跳过不打出卡牌；结算阶段跳过会消耗已经打出的牌。目标提交并进入对方的防御响应后，使用者不能再撤回攻击。自动结算且不需要选择目标的效果仍自动执行。
- 手牌上限为 7 张；暂无回合计时和断线续局。对方退出后原局结束，房间可接受新玩家开始新局。
- 当前设计文档中的全部普通牌与亡语均已加入。0.7 调整桌面卡牌布局和查看 / 出牌交互，继续使用已确认的卡牌配置和结算规则。
